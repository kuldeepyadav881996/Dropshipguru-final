# DropshipGuru Landing Hero

Pixel-accurate dark-themed SaaS hero built with **Next.js 16**, **Tailwind CSS v4**, **Framer Motion**, and **Recharts**.

## Run locally

```bash
cd dropshipguru-landing
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Theme tokens

Defined in `tailwind.config.ts` and `src/app/globals.css`:

- `gold` — `#F5B400`
- `goldDark` — `#FF8C00`
- `purple` — `#8B5CF6`
- `bgDark` — `#05050A`
- `cardDark` — `#12121A`

Fonts: **Playfair Display** (headings), **Poppins** (body/UI).
